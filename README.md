# ตารางชีวิต (iPad web app)

แอปเว็บแบบติดตั้งลงหน้าโฮม (PWA) ใช้ออฟไลน์ได้ ข้อมูลเก็บไว้ในเครื่อง

## ไฟล์

```
index.html             ตัวแอปทั้งหมด
manifest.webmanifest   ชื่อแอป ไอคอน สี
sw.js                  ทำให้เปิดได้ตอนออฟไลน์
icons/                 ไอคอนแอป
```

ต้องเปิดผ่าน `https://` เท่านั้น เปิดไฟล์จากเครื่องตรงๆ จะติดตั้งไม่ได้

## โฮสต์แบบที่ 1: GitHub Pages

1. สร้าง repo ใหม่ เช่น `lifetable`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ไว้ที่รากของ repo
3. ไปที่ Settings > Pages เลือก Branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/lifetable/`

## โฮสต์แบบที่ 2: Firebase Hosting

```bash
npm install -g firebase-tools
firebase login
firebase init hosting      # public directory: .   single-page app: No
firebase deploy
```

## ติดตั้งลง iPad

1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าโฮม แอปจะเปิดเต็มจอ ไม่มีแถบ Safari

## เรื่องข้อมูล

- ข้อมูลอยู่ใน iPad เครื่องนั้นเท่านั้น ไม่ได้ซิงก์ข้ามเครื่อง
- แอปที่เปิดจากหน้าโฮมจะมีที่เก็บข้อมูลแยกจาก Safari ปกติ ถ้าเคยลงข้อมูลไว้ใน Safari ให้ส่งออกไฟล์ .json จากหน้าตั้งค่า แล้วนำเข้าในแอป
- ถ้าลบแอปออกจากหน้าโฮม ข้อมูลจะหายไปด้วย ควรกด "ส่งออกไฟล์ .json" ในหน้าตั้งค่าเก็บไว้ใน iCloud Drive เป็นระยะ
- ย้ายข้อมูลจากหน้าเว็บเดิมใน Claude: เปิดหน้าเดิม ไปที่ตั้งค่า กดส่งออกไฟล์ .json แล้วมากด "นำเข้าจากไฟล์" ในแอปนี้

## อัปเดตแอป

แก้ไฟล์แล้วเปลี่ยนค่า `VERSION` ใน `sw.js` (เช่น `lifetable-v2`) ก่อนอัปโหลด iPad จะโหลดเวอร์ชันใหม่ตอนเปิดแอปครั้งถัดไป

## รหัสผ่าน

- เปิดแอปจะมีหน้าเข้าสู่ระบบก่อน ติ๊ก "จำไว้ในเครื่องนี้ 30 วัน" ถ้าไม่อยากพิมพ์ทุกครั้ง
- ออกจากระบบได้ที่ลิงก์ท้ายเมนูซ้าย
- เปลี่ยนรหัสผ่านได้ในหน้าตั้งค่า รหัสใหม่จะเก็บไว้ในเครื่องนั้น
- ในโค้ดไม่มีรหัสผ่านตัวจริง มีแค่ค่าแฮช แต่หน้านี้เป็นแค่ประตูกันคนเปิดเล่น ข้อมูลในเครื่องไม่ได้ถูกเข้ารหัส
- ลืมรหัสผ่าน: ลบไอคอนแล้วติดตั้งใหม่จะกลับไปใช้รหัสเริ่มต้น แต่ข้อมูลในเครื่องจะหายไปด้วย จึงควรส่งออกไฟล์ .json เก็บไว้เสมอ
